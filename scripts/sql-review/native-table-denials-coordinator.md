## Two narrowly distinct native bypass scopes

The exact pinned fixture seed bypasses its 60 declared USER guards and retains
its 40 declared guards. All FK/CHECK/NOT NULL/PK/unique/internal RI enforcement
stays active. All 205 one-row INSERT statements must succeed and commit, and
independent source-derived per-table counts must total 205.

Each exact pinned `*-native-controls.sql` temporarily bypasses only its target
table's declared USER triggers, including its physical guard, inside a transaction
that ends in ROLLBACK and contains no COMMIT. This separate reviewed exception
permits privileged native INSERT/UPDATE/DELETE shape controls without pretending
to satisfy owner atomic proofs or physical/CAS guards. All native constraints and
internal RI triggers remain installed and active. Every mutation must affect one
row; rollback and independent restoration follow before any restricted operation.
The recorded scope is `NATIVE_CONSTRAINT_FIXTURE_VALIDITY_ONLY`.

The independent restoration query compares the complete 100 USER-trigger
table/name/function/body-hash/enabled-state set, in both directions. It runs after
each native-control backend closes and before every restricted probe. A missing,
extra, changed or disabled trigger stops execution. No repair, ENABLE, broader
trigger disable or permission adjustment is performed after a failure.

## Verdict and retained evidence

A native negative requires psql exit 3, no acknowledgement or result row, exactly
one SQLSTATE 42501 ERROR and the matching allowlisted message/routine in aclchk.c.
SCHEMA, TABLE and COLUMN are recorded as actually observed. Table/column gates
require the source-qualified live privilege projection to establish a missing
referenced permission, and a schema gate requires absent schema USAGE. A composite
statement may fail earlier than its selected forbidden column; no selected-column
isolation is claimed. Trigger RAISE frames, generic codes, unrelated native objects,
extra/malformed headers, terminal controls, unsupported text and wrong exits stop.

Native parser errors may include a LINE/caret excerpt. Only a rendering derived
from the exact pinned ASCII probe is accepted, using the PG17.11 60-column/10-column
libpq rule. Excerpts are discarded, never retained. Primary authorities are
[PG17.11 aclchk.c](https://raw.githubusercontent.com/postgres/postgres/REL_17_11/src/backend/catalog/aclchk.c)
and [PG17.11 libpq reportErrorPosition](https://raw.githubusercontent.com/postgres/postgres/REL_17_11/src/interfaces/libpq/fe-protocol3.c).

Every RLS-zero result requires a privileged existing-row count of one; issuer
foreign-row emptiness additionally requires independently existing own and foreign
facts and legitimate own-row visibility. A missing row never supplies a denial.

The operation's client must exit and an independent observer must confirm absence
of its exact PID/backend-start/login/database before row/fingerprint/restoration
observations. PID/xid/backend-start values stay only in memory. Evidence keeps
source hashes, fixed statuses/stages/exit codes, source-bound gate/column labels,
typed counts/Boolean comparisons and per-table data hashes. Post-seed data hashes
are mutation watches only, never a learned expected schema or owner proof.
Unexpected outcomes stop all later cases and persist sanitized partial evidence.
Unconfirmed closure stops observations; the external operator retains controlled
