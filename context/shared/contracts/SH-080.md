## G. Reliability and recovery

**specific.** One applicable active version per key/scope; overlapping activation serialized. Legal content not invented; retirement retains history and no silent retrospective effect.

**idempotency.** For effects, scoped semantic key/fingerprint and durable result replay; different payload conflicts. Pure queries/helpers mutate no source and do not invent command receipts.

**retry.** Unknown external effect reconciles original semantic identity; only transient classified failures retry, bounded by owner policy; terminal/denied/unsupported never guessed success.

**concurrency.** Owner current source token, atomic CAS/reservation/lease fence where required; no cross-owner transaction or count-then-write.

**ordering.** Committed fact identity and source revision/generation; stale cannot resurrect; correction new retained fact. This is not a global revision clock.

**proof.** Actual owner history/effect receipts; sensitive response requires durable Audit acceptance; optional telemetry cannot bootstrap-deadlock its own primitives.

**revocation.** Current owner context/security/grant generation before effect or credential issuance. Actual provider in-flight cancellation/revocation capabilities remain unproven.
