# WF-11 — Privacy verification, erasure, retention, export and restore

Source owners: privacy_data_erasure, identity_access, media_file_access, search_public_visibility, location_safety, observability_ops, payment_payout_tax, review_dispute, consent_disclosure.

| Sequence | Source transition / effect | Completion boundary |
|---|---|---|
| 1 / PRECONDITIONS | Privacy receives request and independently verifies requester | Source owner current registered facts and action policy; fixture data never authority |
| 2 / SOURCE_TRANSITION | complete actual owner field/action/provider inventories and retention facts produce generation instructions | Actual owner source/history/outbox atomic; no network under source database lock |
| 3 / DOWNSTREAM_AND_RECOVERY | actual execution/lawful disposition receipts yield complete accounting and exact-byte export artifact | Actual required owner/effect receipts, not acceptance/telemetry |

**Guards.** Identity supplies evidence, Privacy decides verification/disposition; protocol is not field executor certification; no destructive parent cascade across retained proof; manifest binds actual bytes and ready exact Media artifact; download current grant/proof/expiry

**Failure/recovery.** Accepted is not completed; missing owner/serializer/provider/backup scope remains unresolved; stale generation cannot overwrite outcome; legal retention and backup evidence external; restore replays restrictions/erasure generations before serving

**Eventual consistency.** Source revisions and generation tombstones dominate late delivery; consumers recheck current protected scope. Unknown effect reconciles same semantic identity.

Registered source events: privacy.request_changed.v1, privacy.execution_changed.v1. These are owner facts; source commands/intents/receipts still govern actual effects.
