# WF-01 — Registration, security and actor creation

Source owners: identity_access, consent_disclosure, customer_buyer_profile, professional_eligibility, candidate_application_resume_privacy, track_subscription_entitlement.

| Sequence | Source transition / effect | Completion boundary |
|---|---|---|
| 1 / PRECONDITIONS | Applicable age/eligibility proof before local User | Source owner current registered facts and action policy; fixture data never authority |
| 2 / SOURCE_TRANSITION | Identity provisions verified local identity, then profile owner creates one-to-one branch | Actual owner source/history/outbox atomic; no network under source database lock |
| 3 / DOWNSTREAM_AND_RECOVERY | source commits default-Free Track intent and security notice separately | Actual required owner/effect receipts, not acceptance/telemetry |

**Guards.** Provider mapping/current security generation; exact presented Consent and source eligibility; Role acts only on later protected action; source fact branch does not require the same protected action

**Failure/recovery.** Provider shadow account is not membership; replay same provisioning key; profile creation does not await Track; lost enrollment response reconciles without inferring Free or downgrading paid selection

**Eventual consistency.** Source revisions and generation tombstones dominate late delivery; consumers recheck current protected scope. Unknown effect reconciles same semantic identity.

Registered source events: identity.security_changed.v1. These are owner facts; source commands/intents/receipts still govern actual effects.
