| Sequence | Source transition / effect | Completion boundary |
|---|---|---|
| 1 / PRECONDITIONS | Committed typed source and current audience | Source owner current registered facts and action policy; fixture data never authority |
| 2 / SOURCE_TRANSITION | Messaging source commit creates safe Notification intent/realtime invalidation; owner Search intent yields derived index | Actual owner source/history/outbox atomic; no network under source database lock |
| 3 / DOWNSTREAM_AND_RECOVERY | protected recipients/results refetch under current authority | Actual required owner/effect receipts, not acceptance/telemetry |

**Guards.** Order context for Booking/Dispute; thread membership not inferred from broad Org role; finite intent/template/action route and private endpoint generation; no message body/resume/exact location in events or public Search; Candidate collection protected

**Failure/recovery.** Source commit independent of Notification/Search/telemetry outage; stale endpoint callback ignored; audience checked subscribe/emission/reconnect; unknown provider delivery not legal service or source completion; complete snapshot required before orphan deletion

**Eventual consistency.** Source revisions and generation tombstones dominate late delivery; consumers recheck current protected scope. Unknown effect reconciles same semantic identity.

Registered source events: messaging.message_created.v1, messaging.membership_changed.v1, candidate.discovery_changed.v1, location.disclosure_changed.v1. These are owner facts; source commands/intents/receipts still govern actual effects.
