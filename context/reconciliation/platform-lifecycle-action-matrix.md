# Platform lifecycle/action matrix

Architecture review only. The structured companion contains exact source surfaces, all 80 rows, 268 family links and 563 unique source-record references. Common controls below apply to every row; the owner and action-specific constraints are cumulative. This is not a DTO or runtime freeze.

**authority.** Identity trusted actor, Role registered action/relationship and action-bound assurance under R068; own lifecycle and current source predicates remain additional checks. Internal fact branches follow R085; unknown/unavailable never allow.

**consent_entitlement_hold.** Use only actual action-required exact purpose/version consent, typed Track benefit/acquired Order rights and registered Hold target/action. Non-applicable checks do not invent new gates; unregistered required scope is unsupported, never silently permissive.

**proof.** Sensitive disclosure requires durable R023 Audit acceptance first. Privileged mutation commits owner history and audit/outbox intent atomically. Ordinary diagnostics may degrade. No secrets in events/telemetry.

**failure.** Scoped semantic identity plus canonical fingerprint; same replay returns original receipt, changed fingerprint conflicts. CAS/fenced claims protect current owner version. Unknown external effect reconciles before new attempt; no cross-owner transaction.

**events.** Only R069 registered facts and explicit owner commands/intents; source history/outbox atomic, subscriber+event dedupe plus economic/domain effect identity; gap/retraction/tombstone/source-currentness rules. Command acknowledgment is not effect completion.

**qualification.** Architecture agreed; UNSTABLE. Exact executable DTOs/transport, concurrency, source freshness, server/RLS parity, migrations, providers and runtime fixtures are not certified. Privacy protocol is not per-owner field/action executor proof.
