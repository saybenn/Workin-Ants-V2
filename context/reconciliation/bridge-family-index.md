# Bridge boundary family index

All **563** historical records are assigned exactly once to **268 conservative boundary families**. This is normalization only: zero duplicate closures and zero frozen contracts. The [machine-readable index](bridge-family-index.json) preserves source hashes, producer/consumer facets, inherited profiles and reverse membership.

Families use canonical SH identity, canonical operation owner and historical boundary direction/kind together. Owner-specific and bundled operations retain their explicit endpoint and direction facets inside each family; a shared protocol family does not assert identical source DTOs. Fourteen paired concerns use explicit matching owner, purpose and direction evidence; historical operation names remain unapproved where the source says so. Other unnamed contracts remain singletons rather than being guessed equivalent.

A repeated operation across multiple families is a **directional facet or scope mismatch to review**, not another independent platform decision. Use the JSON `shared_operation_directional_family_index` to reconcile those facets once against the owner. The cross-rail matrix lists evidence coverage, not mandatory consumers or active integrations.
